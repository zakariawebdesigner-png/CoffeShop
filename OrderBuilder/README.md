   
# OrderBuilder


This folder is responsible for building the customer's order.

It takes the customer's choices and puts them together into one
complete order.

For example, when the customer chooses:

- A coffee
- A size
- A temperature
- A type of milk
- A amount of sugar

The functions inside this folder take these choices and store them
in the order record.

In simple words:

The customer makes choices → OrderBuilder collects them → A complete
order is created.
